版本化接口：/api/v1。下载 OpenAPI 3.1.1 · 返回应用

写入使用 X-Workspace-Client: jieheng 与 Idempotency-Key（8–100 个可见 ASCII 字符）。项目内写入另带当前 ETag 作为 If-Match。旧版本 412，缺少版本 428，同一幂等键不同内容 409，校验错误 422。错误为 application/problem+json，含 request_id。本地标识不是身份认证。

新增资源 201，替换资源 200。所有操作采用事务，运行数据库不随交付包分发。企业模式提供会话与项目权限；AI 任务返回 202。主动模型测试、登录、检索和账户建立等接口的幂等语义以各接口为准。部署和备份见 ENTERPRISE_DEPLOYMENT.md，模型及知识见 AI_ASSISTANCE.md。
