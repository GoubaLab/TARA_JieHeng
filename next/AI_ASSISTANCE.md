# 模型服务与辅助分析

界衡的 AI 功能用于生成可审阅的工作产品，风险计算、引用检查、并发控制、验证和基线仍由平台领域规则执行。不配置模型也可以完成全部人工流程。

## 使用顺序

1. 管理员在「模型服务」添加企业 Ollama、OpenAI 兼容网关、OpenAI Responses 或 Anthropic Messages 服务。分别指定分析、视觉和向量模型；模型 ID 由实际服务提供，平台不猜测可用型号。
2. 保存并测试连接，必要时发现模型列表。视觉连接测试仅验证通信；识图准确性必须用图片任务核对。兼容 Chat 网关可选择 `max_tokens` 或 `max_completion_tokens`，高级路径用于企业网关的接口路径差异。
3. 在「企业知识」录入有权使用的文本/Markdown，注明来源、版本及组织/项目范围。在项目中选向量模型建立索引，任务完成后可进行语义检索。没有向量索引时仍可用关键词检索。
4. 在项目「辅助分析」选择图片建模、全流程分析或质量复核，选择模型服务顺序、提示词、资料范围及负责人。外部地址必须逐次明确允许；首选、备用、检索向量服务均显示在发送范围内。
5. 检查结果的假设、待确认项、来源片段和原生图形预览，再勾选审阅确认、采用草案。采用只允许与任务依据相同的项目修订；旧版本任务必须重新分析。
6. 在原有工作台继续编辑、确认评分与处置，录入实际验证证据，完成交付检查并建立基线、导出静态报告。AI 处置先进入待确认建议，打开处置表单可预填；确认前不作为已批准决策。

## 模型服务管理

- 独立设计参考 [CC Switch](https://github.com/farion1231/cc-switch) 的服务配置、模型发现、故障切换与健康管理思路；没有复用其界面或源码。
- API 根地址、接口协议、内网/外部范围、三种用途模型、启停、显示优先级、超时、输出上限、重试次数、可选路径和价格均可配置。
- API Key 写入后使用 AES-GCM 加密，读取接口不返回明文或密文。数据库旁的 `.key` 是解密主密钥，权限为 0600；备份必须包含它。项目正文和整个 SQLite 文件并未因此整体加密。
- 配置导出、复制和导入均排除凭据。导入配置默认停用，填写凭据并测试后再启用。不读取其他程序的凭据，不同步 CC Switch 配置文件。
- 内网服务仅能连接回环/私有 IP；外部服务要求 HTTPS 且拒绝私有 IP。DNS 在连接时核对地址，禁止重定向和环境代理，拒绝链路本地元数据地址。企业仍应设置自身出口策略。
- 每次任务明确选择最多 4 个有序服务；只在这些服务之间切换。401/403、非法响应及输出不完整直接停止；网络故障、408、429、5xx 可有限重试。单次超时 5–180 秒，重试 0–2 次；连续 3 次失败熔断 1 分钟，测试成功可恢复。
- 记录调用次数、Token、时延、失败、熔断及按配置单价估算的成本。估算不是供应商账单，未配置单价时为 0；网络超时后的上游实际费用可能不可知。
- 不支持任意自定义认证脚本、OAuth 登录代理、云厂商专有签名、自动购买额度或任意模型工具执行。

## 企业知识与提示词

知识属于使用者自行维护的资料，与已撤下的历史私有参考库分开。记录来源、版本、范围、启停及修订；资料正文最大 120,000 字符，当前支持粘贴与 UTF-8 文本/Markdown，不声称可以自动解析任意 PDF/Office 文档。

索引每段最多 800 字符、重叠 120 字符；调用所选服务真实的 embeddings API，校验维度、数量、有限数值和非零向量。向量保存在本地 SQLite，检索使用余弦相似度与关键词排序的 RRF 融合。限定组织资料与当前项目资料，法规只检索当前项目已勾选的条款。索引正文或模型配置变化后失效，页面标记待重建；没有匹配索引时明确显示关键词检索。当前候选上限 20,000 片段，适合单企业适量资料；更大规模需要替换检索存储实现并压测，不能当成已部署的大规模向量集群。

内置三种用途模板；组织模板可创建、复制、编辑、启停，编辑保留旧版本。每次任务保存当时的提示词、协议契约、模型配置摘要、输入哈希与引用原文片段，后续模板修改不影响旧任务的追溯。不可变的系统约束位于 `server/internal/assurance/ai_proposal.go`，结构契约为 `jieheng.ai-work-products/1`。模板只改变分析指引，不能扩张模型写入权限。

## 数据与任务边界

发送内容为任务说明、当前工作产品、检索命中的资料片段；图片任务额外发送所选 PNG/JPEG（最大 1 MB、边长不超过 6000、总像素不超过 1600 万）。不发送账号数据、模型密钥列表、导入工作簿原文件或验证附件。项目文字和资料仍可能包含敏感内容，目的地应由企业管理员配置，并由执行人员按界面范围选择。

模型没有 shell、网络浏览器或任意 API 工具权限，不能执行文档中的指令。模型结果必须通过 JSON、引用、原生 DFD 及领域关系校验；仅已提供的来源 ID 能作为引用，不能编造法规出处、验证通过、签字或客户确认。图形采用后成为可拖动、可编辑、可静态导出的原生架构，遵循项目原有资产生成模式。

任务持久化，最多 2 个执行、12 个等待/执行中任务，单任务总时限 20 分钟。可取消，服务重启会将遗留任务标为中断，不自动重新计费。任务失败可基于当前项目重新生成；若服务配置已变化，须新建任务重新选择目的地。任务期间固定服务配置，避免管理员编辑地址把已经提交的任务转发到另一目的地。

采用草案在同一事务中校验项目修订、知识来源版本，建立还原点、写入工作产品、记录来源与幂等结果。采用只增加一次项目修订。还原会生成新修订并保留还原前快照和既有冻结基线，评估方法需重新确认。还原点在同一数据库中，不能替代独立备份。

Excel/HTML 按需增加「辅助分析追溯」「处置待确认建议」表；原有静态图与人工验证规则保持有效。未知损害评分保留为待评估，不以部分已知分数替代完整风险。

## 验证与实际能力

原创合成集成测试覆盖四种协议适配、真实数值向量接口、范围隔离、凭据不泄露、显式故障切换、取消、重启、幂等、原生图片建模、原子采用、恢复及报告追溯。测试服务返回固定合成响应，证明的是协议和产品流程，不代表真实模型的分析质量。接入实际企业模型后，应使用企业允许的基准图和分析样例评价识图、漏报、引用准确率、成本和时延。
