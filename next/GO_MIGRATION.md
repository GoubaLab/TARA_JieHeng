# Go 后端状态

当前主运行时为 Go，领域规则、风险评分、参考目录、法规读取、事务、审计回执、HTML/JSON 报告和 Excel 生成管理均已迁移。启动 `./start.sh`，不调用旧 Python 服务。`start.py` 只执行同一个 Go 可执行文件。

已有新应用 SQLite 表可直接读取；创建项目增加独立幂等回执表，不删除旧业务表。规范 JSON 编码兼容旧整数/浮点身份和 SHA-256，原决策、证据和基线不会仅因语言变化失效。新增元数据省略或默认值也保持旧评估摘要兼容；真实领域、OS、通信或方法变化会触发复核。

API 使用 `/api/v1`，不保留旧 `/service` 路由。版本条件、幂等回执、错误结构、参数类型与范围都由服务端执行。测试包含合成兼容夹具、事务与并发、引用约束、HTTP、算法边界及静态报告。

旧 Python 实现、历史私有夹具、旧服务/分发物已在工程外备份后退休。不要恢复旧目录来补资料，也不要用旧服务读写当前运行库。需回退时，应先停止当前服务并完整保留当前数据库，再在隔离目录使用受控备份；不把备份作为发行内容。

Excel 已改用公开 Go 依赖 Excelize，在后端原生生成 17 张工作表，不依赖 Node 或 Codex 专用组件。Go 二进制按目标平台构建，默认本地交付提供 macOS arm64。
