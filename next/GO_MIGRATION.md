# 后端运行与数据兼容

## 运行与构建

后端使用 Go 实现领域规则、风险评分、资料与法规读取、事务、审计回执，以及 HTML、JSON 和 Excel 报告。`./start.sh` 启动 Go 可执行文件；`start.py` 是兼容启动入口，不承担应用服务。

Go 二进制应按目标操作系统和处理器架构构建。Excel 通过 Excelize 在后端生成，基础报告包含 17 张工作表，扩展工作产品按需增加追溯表。运行和导出无需 Node.js、Python 或 Office。

## 数据兼容契约

持久化使用 SQLite。项目创建具有独立幂等回执；业务变更在事务中保存工作产品、修订与审计记录。升级应保留现有业务表和冻结基线。

规范 JSON 编码保持数值表示与 SHA-256 摘要的兼容性。可选元数据缺省值经过归一化，不会仅因默认字段补全而使已有决策或证据失效。领域、OS、通信语义或评分方法的实质变化会触发相关工作产品复核。

## 接口与验证

公开 API 使用 `/api/v1` 资源路径。版本条件、幂等回执、统一错误结构、参数类型与范围由服务端校验。测试覆盖数据兼容、事务与并发、引用约束、HTTP 契约、算法边界和静态报告。

## 升级与恢复

升级前建立一致性备份并校验完整性。恢复时使用独立目录，核对数据库和配套密钥后再切换服务，避免不同版本同时写入同一数据库。具体操作见 [企业部署与备份恢复](ENTERPRISE_DEPLOYMENT.md)。运行数据与备份不属于源码发行内容。
